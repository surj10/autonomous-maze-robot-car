# Documentation notes

## Source and scope

This repository was assembled from the single supplied first-year robot-car poster. Text has been rewritten for clarity, while the objective, named components, reported detection range, team names and development challenges remain grounded in that source. The poster does not state a project date, identify a final-car photograph, allocate individual responsibilities or establish successful maze completion. Those details have not been invented.

## Motor-driver label

The poster calls the H-bridge “LM293” and describes two-motor drive and built-in protection. Manufacturer documentation identifies LM293 as a dual comparator and L293/L293D as half-H driver devices. A typo is plausible, but the photographs do not confirm the actual marking. The README retains the uncertainty and does not silently substitute L293D or repeat the protection claim.

References:
- Texas Instruments LM293: https://www.ti.com/product/LM293
- Texas Instruments L293/L293D datasheet: https://www.ti.com/lit/ds/symlink/l293.pdf
